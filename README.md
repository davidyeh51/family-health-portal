## 🌟 核心特色與系統架構

### 1. 雙軌認知導航體系 (Dual-Tier Cognitive Framework)
針對不同知識深度的使用者設計分層體驗：
- 🌱 **【入門者視角 · 3 秒行動指南】**：
  - 去除晦澀醫學名詞，提煉為「3 秒結論心法」
  - 具備每日生活實操「行動檢核清單 (Checklist)」
  - 揭露日常生活常見避坑點（如：橫向大拉鋸刷牙、65℃ 燙水致癌、劇烈補覺時差）
- 🧠 **【進階者視角 · 系統思考與決策模型】**：
  - 解構人體底層生理學與神經內分泌機制（迷走神經張力、LPL 脂蛋白脂肪酶、類淋巴夜間排毒、細胞自噬 AMPK/mTOR 通路、角質層磚牆學說）
  - 匯聚國際頂級期刊（NEJM, Lancet, JAMA, Circulation, Cell Metabolism）臨床實證
  - 建立因果關係決策樹與風險評估矩陣

### 2. 無雜訊頂尖顧問簡報規範 (/zero-noise-pptx)
- **形式對應邏輯（Form Follows Logic）**：每一頁嚴格匹配前 BCG 顧問森秀明審視 10 萬頁投影片提煉之 **8 大邏輯版型**：
  1. `版型 1：一對一論法 (One-to-One)` — 單一關鍵指標高亮（如：快走 8000 步死亡率拐點、睡眠 7–8 小時 U 型曲線）
  2. `版型 2：並列論法 (Parallel)` — 2–4 欄對稱 Bento 卡片結構（如：四格餐盤三大支柱、工位久坐急救 4 招）
  3. `版型 3：結合論法 (Combined Tree)` — 金字塔三層演繹樹（如：家庭健康三層架構、皮膚屏障磚牆結構、秋冬免疫債演繹）
  4. `版型 4：連鎖論法 (Chain / Flow)` — 因果時序長箭頭推進（如：行為改變習慣複利鏈路、16:8 輕斷食代謝時序）
  5. `版型 5：麥肯錫論法 (McKinsey Matrix)` — 流程階段 × 診斷維度矩陣（如：FITT-VP 個人運動處方、牙具挑選四字矩陣）
  6. `版型 6：對立論法 (Opposition)` — 正反兩極維度化對比（如：疾病管理 vs. 健康管理、原型食物 vs. 超加工食品、水溫致癌對照）
  7. `版型 7：比較論法 (Comparison)` — 共通交集點與兩側差異點（如：體感口渴 vs. 尿液比重判定、微午睡 vs. 長睡眠慣性）
  8. `版型 8：BCG 2×2 矩陣 (BCG Matrix)` — 雙軸四象限戰略組合（如：空氣品質 × 換氣量防護矩陣、久坐時長 × 運動補充四象限）
- **Action Title 由上而下動線**：每頁標題均為完整結論句，嚴禁主題詞。
- **逐頁三段式講稿備忘錄**：包含 ① 本頁結論主張、② 補充醫學依據、③ 下一頁轉場鋪墊。

### 3. 未來可擴充性架構 (Scalable Architecture)
- 資料層完全解耦於 `data/health_kb_data.json` 與 `js/health_kb_data.js`。
- 後續課程（021～100 講）匯入時，只需追加 JSON 項目，搜尋引擎、模組篩選、雙軌卡片與互動簡報將**自動即時生成**，完全無需修改前端程式碼。

### 4. 即時全文關鍵字搜尋 (Instant Keyword Search)
- 支援標題、分類標籤、入門行動指令、進階生理機制的多維即時索引檢索。
- 內建熱門標籤快選膠囊（#睡眠天花板、#四格餐盤、#FITT-VP、#避免久坐、#副交感呼吸、#PM2.5、#16:8輕斷食、#巴氏刷牙法、#比目魚肌 等）。

## 🛠️ 本地開發與簡報自產

### 1. 本地啟動網頁門戶
在專案目錄下啟動本機伺服器：
```bash
python -m http.server 8000
```
瀏覽器造訪：`http://localhost:8000`

### 2. 本地重新產出實體 PPTX 簡報檔
本專案整合 `zero-noise-pptx` 核心生成腳本：
```powershell
python "export_presentation_pptx.py"
```
將根據 `data/pptx_slides.json` 重新編譯生成 `family_health_100_zero_noise.pptx`。
